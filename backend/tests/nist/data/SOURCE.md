# Source of the files in this folder

NIST Statistical Reference Datasets (StRD), Information Technology Laboratory, NIST. Public domain (US government work). The files are byte-identical copies of the originals; each carries its certified values in its header. Downloaded on 2026-11-28.

Index: https://www.itl.nist.gov/div898/strd/
